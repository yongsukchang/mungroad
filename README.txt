GitHub 업로드 방법
1. 기존 저장소 yongsukchang/mungroad 에서 Code 탭으로 이동
2. Add file → Upload files
3. 이 폴더의 파일과 articles 폴더를 전체 업로드
4. 같은 이름 파일은 교체되도록 커밋
5. Settings → Pages에서 Custom domain이 mungroad.kr인지 확인
6. https://mungroad.kr/sitemap.xml 열어 mungroad.kr 주소가 보이는지 확인
7. Search Console에서 sitemap.xml 재제출 또는 읽기 상태 확인

AdSense 관련
- 아직 AdSense 게시자 ID가 없으므로 ads.txt와 광고 코드는 넣지 않았습니다.
- 승인/등록 후 제공되는 pub ID를 받아 ads.txt와 광고 코드를 추가하세요.
- 콘텐츠가 색인되고 사이트가 정상 작동하는지 확인한 뒤 심사를 신청하는 편이 좋습니다.

주의
